# AI Home Assistant Architect

A local-first AI architecture and solar health management platform for Home Assistant OS.

## First product: Solar Sentinel

Solar Sentinel is an experimental HAOS App that discovers solar-related entities and detects telemetry and production-health problems. Version 0.1.0 is read-only: it cannot control equipment, edit automations, contact vendors, or submit warranty claims.

Target: Home Assistant OS on amd64, Intel i5-8500B, 32 GB RAM, with CPU-first Ollama support planned using `qwen3:8b`.
